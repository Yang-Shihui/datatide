# 可视化选型决策

按数据的"问题形态"选图，而不是按数据类型：

## 决策表

| 你想回答的问题 | 数据形态 | 图型 |
|---|---|---|
| 谁最多/排名如何 | 类目 + 一个指标 | 横向 bar（降序） |
| 随时间怎么变 | 时间序列 ≤3 组 | line（可带面积渐变） |
| 各部分占多少 | 构成，类目 ≤6 | pie（>6 类改横向 bar） |
| 构成 + 总量趋势 | 时间序列堆叠 | 堆叠 bar / 堆叠面积 |
| 两个指标什么关系 | 两列数值 | scatter |
| 目标完成度 | 实际 vs 目标 | bar + 参考线（markLine） |

## 平台约束（必须遵守）

- 单个 series ≤500 点，超出先在 SQL 里聚合
- bar/line 的类目轴 ≤20 个（多了旋转标签或分桶）
- 多系列对比时系列名用业务词汇（"2025年"），不用字段名（"order_year"）
- pie 从大到小排列，最后一项可合并为"其他"

## 反模式

- 折线图表达无序类目的对比（应该用 bar）
- 双 y 轴（误读风险高，拆两张图）
- 3D、雷达图（本平台不支持且难读）
